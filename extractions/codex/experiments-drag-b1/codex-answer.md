## Setup

- **Coverage.** The 13 constant-penetration tables contain 272 printed run rows. The report gives 363 tests for the entire drag program and lists both constant-penetration and constant-pressure tests in the program parameters. AM-68-1 Vol. I, text printed 4-4, PDF 189, Fig. 4-2, printed 4-5, PDF 190, and Fig. 4-6a, printed 4-8, PDF 193, through Fig. 4-16, printed 4-20, PDF 205.
- **Bed and drive.** The Bendix rig used two identical bins, approximately 10 ft long by 3 ft wide, with false bottoms giving 11 to 12 inches of soil. The piston was mechanically locked to set penetration. Rubber cords accelerated the rail carriage, then the cam rod and friction drive wheel held speed. The rig description gives six feet for the constant-speed phase. The example record covers approximately five feet. AM-68-1 Vol. I, text printed 3-1, PDF 142, text printed 3-5, PDF 146, Fig. 3-2, printed 3-6, PDF 147, text printed 3-7, PDF 148, text printed 3-13, PDF 154, and text printed 4-4, PDF 189.
- **Footpad and depth.** The illustrated 1/6-scale steel footpad simulates the LM contours and uses a ball pivot and anti-yaw link. The tables label diameters 4 and 6 inches. The overview reports 4.10 and 6.17 inches for the drag scaling tests. I used the table labels in the CSV. The report defines `d` from the soil surface to the pad bottom at zero pitch. The `loading` field carries that printed depth setting, and a separate starting depth is unreported. Fig. 4-5 supplies the record for run 2-20 in Fig. 4-7, a run-level match. AM-68-1 Vol. I, text printed 1-7, PDF 21, text printed 3-13, PDF 154, Fig. 3-10, printed 3-15, PDF 156, text printed 4-4, PDF 189, Figs. 4-4 and 4-5, printed 4-6, PDF 191, and Fig. 4-7, printed 4-11, PDF 196.
- **Gravity and replication.** Barred `g_p` is the bed average of dynamic penetrometer peak decelerations, expressed in g. The report defines Earth gravity as 32.2 ft/s², which reproduces the printed velocity ratio of 13.0 for run 1-29 to the table’s precision. Earth gravity is therefore inferred for the drag setup. Exact pad and pivot geometry, initial attitude, and the actual fill depth within the stated range require assumptions for a run-level simulation. - **Bed history.** The report describes 49 beds for the first 49 RS Loose tests and documents soil removal, handling, and redeposition. It traces increased RS degradation to vacuum handling after 1-75. I could not establish that any listed run reloaded an intact bed, so `mcc_relevant` is `no` throughout.
