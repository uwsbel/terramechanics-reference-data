B LPT Started Two Inches Below Soil Surface

Test Bin 108 Inches by 36 Inches

Slope = AγN_q = 54 lbs./in.

∴ $N_q$ = 54 / Aγ = 54(1730) / 12.6(108) ≈ 69

∴ φ ≈ 39°

φ (Direct Shear Test) = 39.5°

Intercept = 140 lbs. = 0.3 ADγN_γ

$N_γ$ = 140(1730) / 0.3(12.6) 4(108) = 148

=> φ = 42°
