Terramechanics Reference Data

Measured soil tests for judging terramechanics simulations.

This site provides laboratory soil tests as numbers: for example, the force needed to push a cylinder into sand as it goes deeper, or the stress at which a soil sample fails in shear. Each test comes with what one would need to set up the same test in a simulator (the soil, how its bed was prepared, the tool and how it moved), and states what the original report leaves out. Every number links to the page of the report it was read from.

This is the beginning of an effort to collect, curate and share well-documented test data that can be used to judge the simulation tools used in terramechanics. To that end, the site also shows how the data are meant to be used with an open-source simulator to gauge its accuracy.

For instance, one set of tests comes from a 1968 NASA study for the Apollo Lunar Module, in which twelve soil conditions were tested on Earth to predict how the lander’s footpads would behave on the Moon.

The collection will grow with further tests, and contributions are welcome of two kinds: data from new physical tests, and scripts that run virtual experiments mirroring the physical tests hosted here.

Start here

One test, from its setup to its citation: LPT 24, a 4-inch (102 mm) cylinder pushed into a bed of dense red scoria.

  1. Its page gives the setup as a virtual experiment card: the soil, the bed, the tool and the motion, each value with the page it is printed on, and what the report leaves out.
  2. Its points are in observations.csv: load against penetration in SI units, with the value as printed kept beside each one.
  3. Each point carries a reading bound, how precisely it could be read off the printed figure (not the scatter of the experiment), and a status that says how it was checked; the Glossary defines both.
  4. Each point traces to the scan: the Figures page draws the two readings over the printed figure, Fig. 2-42.
  5. To cite it: the release by its DOI, and the record by its id and source page, for example record b68-lpt-024, AM-68-1 Vol. I, Fig. 2-42, printed 2-77, PDF 102 (Download gives the entries).

In the collection

Measured data for 85 direct shear tests, 22 load-penetration tests, 11 sonic modulus tests, 3 dynamic penetrometer tests, 3 footpad impact tests and 2 drops of a 1/6-scale Lunar Module model, on these test soils:

code soil
RS red crushed volcanic scoria, narrowly graded
PS white crushed pumice, narrowly graded
RSM-a RS mixed with crushed marble, 5 to 7 by weight, narrowly graded
RC2 red crushed volcanic scoria, broadly graded
SS white silica sand (Wedron 4040), narrowly graded
LSM broadly graded scoria (RC2) mixed with air-floated clay
RSM-b RS mixed with crushed marble, 1 to 3 by weight, narrowly graded
