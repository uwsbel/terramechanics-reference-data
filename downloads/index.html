Downloads

Every file on this page is the repository file itself, as of the revision named in the footer; the site never holds a separate copy of a number. Select a file name to open or download it. Each CSV has a JSON sidecar beside it that carries source, conversion factors, status definitions and the two submissions it was reconciled from.

Files of each record

  • data/experiments/<id>/observations.csv and series.json: the digitized points of a figure, with pixel coordinates, calibration residuals and reading bounds. Available for the 192 records whose figures have been read, and linked from each of their pages; the figures of the other records have not been read yet.
  • data/experiments/<id>/runs.csv and runs.json: a printed table of runs, one physical test per row. Available for the 3 records that are tables of runs, and linked from their pages.

Not yet available

  • data/experiments/<id>/setup.json: the setup of each test as machine-readable fields. Until it exists, each record page gives the setup as a table.

How to cite

Cite the data release used and the report the numbers come from. Where numbers are used, give the record id and the source page as well, for example b68-lpt-027, AM-68-1 Vol. I, Fig. 2-29, printed 2-55, PDF 80.

Record ids are permanent: a record keeps its id and its page address from one release to the next. A record that is merged into another or withdrawn keeps a page that says where its data went, and the changelog of the release lists the change. A citation of a release by its DOI always reaches the files of that release.

The data release:

@misc{negrut2026terramechanics,
  author       = {Negrut, Dan and Serban, Radu},
  title        = {{Terramechanics Reference Data}},
  howpublished = {Data set, version 1.0.0},
  year         = {2026},
  publisher    = {Zenodo},
  doi          = {10.5281/zenodo.24477009},
  url          = {https://doi.org/10.5281/zenodo.24477009}
